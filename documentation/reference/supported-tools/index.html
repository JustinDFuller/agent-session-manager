Supported Tools

The agent tools that Agent Session Manager can detect, configure, and launch in panes.

Agent Session Manager supports these agent tools in panes:

Tool Enable it in Pane guide
Claude Code Settings → Harnesses → Claude Code Claude Code
Codex Settings → Harnesses → Codex Codex
Cursor Settings → Harnesses → Cursor Cursor
OpenCode Settings → Harnesses → OpenCode OpenCode

Common support

Every supported tool can:

  • run in a pane after its command is available in the selected shell;
  • use the shared session, branch, or worktree flow;
  • use a profile when the profile targets that tool;
  • receive tool-specific CLI options from the New Pane sheet; and
  • show app-owned information such as the worktree, branch, session duration, changed lines, and pull-request status when those values are available.

Tool-specific options and status information vary by tool. Use the tool-specific guide for setup steps and the relevant how-to guide for configuration.
